# 마케팅 성과 대시보드

캠페인 데이터를 읽어 **"다음에 무엇을 할지"**까지 제안하는 대시보드.
청년 K-뉴딜 아카데미 Adobe AI 콘텐츠 마케팅 과정(AGM 1기 · 대전 한남대학교) 캡스톤.

## 이 프로젝트가 답하려는 질문

> 광고를 돌렸는데, **다음엔 어디에 더 쓰면 되지?**

성과를 보여주기만 하는 대시보드는 많습니다. 이 대시보드는 거기서 한 걸음 더 가서
**채널 재배분 · 소재 교체 · 타겟 집중 · 랜딩 개선 · 실험 판정**을 근거와 함께 제안합니다.

## 5분 안에 실행하기

```bash
npm install
npm run dev        # http://localhost:3000
```

환경변수 없이도 전부 동작합니다. 대시보드는 샘플 데이터로 채워지고,
랜딩은 수집만 건너뜁니다.

## ⚠️ 샘플 데이터

대시보드의 모든 수치는 **가상 데이터**입니다. 실제 집행 결과가 아니며,
화면 상단에 항상 「샘플 데이터」 배지가 노출됩니다.

- `src/data/mock/generate.ts` — 업종 5종 × 채널 5개 × 28일
- **시드 고정 난수**를 씁니다. 새로고침해도 숫자가 변하지 않습니다 —
  발표 중에 값이 바뀌면 고장난 것처럼 보이기 때문입니다.
- 업종마다 채널 성향·소재 피로도·퍼널 병목이 다르게 설정돼 있어
  **업종을 바꾸면 제안도 실제로 달라집니다.**

실제 계정을 연결하려면 `INDUSTRIES` 대신 광고 API 응답을 같은 형태
(`src/data/mock/types.ts`)로 매핑해 넣으면 화면은 그대로 씁니다.

## 제안 엔진

`src/lib/insights.ts` — 규칙 5개.

| 규칙 | 트리거 |
|---|---|
| 예산 재배분 | 채널 간 ROAS 격차 60%p 초과 |
| 소재 교체 | 초반 대비 후반 CTR 18% 이상 하락 |
| 타겟 집중 | 특정 세그먼트 CVR이 평균의 1.3배 초과 |
| 랜딩 개선 | 퍼널 최대 이탈 구간 |
| 실험 판정 | 2×2 카이제곱 p < 0.05 |

**LLM을 호출하지 않습니다.** 판단 근거를 화면에 그대로 보여줄 수 있어야 하기
때문입니다. "AI가 그렇게 말했다"는 마케터가 사장님께 할 수 있는 설명이 아닙니다.
각 제안은 근거 수치 · 실행 방법 · 기대 효과와 **그 계산식**을 함께 노출합니다.

우선순위는 절대 임계값이 아니라 **상대 순위**로 매깁니다. 임계값으로 하면 다섯 개가
전부 "높음"으로 나오고, 그러면 우선순위가 아무 정보도 주지 못합니다.

## 차트

외부 차트 라이브러리를 쓰지 않고 인라인 SVG와 div로 그립니다.
색은 검증된 팔레트만 씁니다.

- 단일 계열 · 순차: 블루 `#2a78d6`
- 퍼널 5단계 순서형: `#86b6ef` → `#104281` (단일 색조, 명도 단조 증가)
- A/B 2계열: `#2a78d6` · `#008300` — 색각이상 ΔE 26.5, 일반시야 ΔE 29.0

이중 축은 쓰지 않습니다. 척도가 다른 두 지표는 차트를 나눕니다.

## Supabase (선택)

랜딩(`/demo`)의 실제 이벤트를 수집하려면:

1. supabase.com에서 프로젝트 생성
2. SQL Editor에 `supabase/schema.sql` 실행
3. `.env.example`을 `.env.local`로 복사해 값 입력

> ⚠️ `SUPABASE_SERVICE_ROLE_KEY`에 **`NEXT_PUBLIC_`을 붙이지 마세요.**
> 붙이면 키가 브라우저 번들에 들어가 DB 전체가 공개됩니다.
> RLS는 익명 키에 `insert`만 허용합니다.
